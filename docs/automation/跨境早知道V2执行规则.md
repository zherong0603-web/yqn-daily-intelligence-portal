# 跨境早知道 V2 执行规则

本文件是“跨境早知道 V2”的最高优先级内容规则。技术执行入口与验收要求见 `docs/automation/工作日晨报执行规则.md`。

## 每日任务

- 每天北京时间 16:00 采集、生成并推送到负责人钉钉个人私聊。
- 市场优先级：美国 > 墨西哥 > 欧洲。第一条必须是美国，除非当天美国没有合格信号；无合格信号时在风险说明中写清原因。
- 重点主题：平台活动、补贴、流量、费用、头程仓配物流、关税、汇率、地缘冲突，以及任何直接影响卖家利润的变化。
- 新闻窗口优先 24 小时；24 小时内不足三条时扩展至 72 小时，不得用更旧内容伪装新稿。
- 所有数字、日期、政策必须可溯源。未经证实的博主爆料只能进入“未证实信息”，不得混入主稿三条。

## 口播规则

固定开场：

“两分钟，听懂跨境事！”

随后接 1–3 秒黄金钩子。A 版必须是荒诞、戏剧化商业场景；B 版必须是反常识口播。A/B 正文完全一致。

正文固定结构：

“跨境卖家注意……”
“今天老王带你看三件事。”
“第一……”
“第二……”
“第三……”

每条必须讲清：

1. 发生什么；
2. 具体数字；
3. 生效时间；
4. 影响哪些卖家；
5. 实际涉及多少钱。

不要空泛观点、AI 腔或冗长解释。禁止使用“流量不等于利润”“某一段降价不代表全链路便宜”“大家要注意成本”等没有具体信息增量的句子。只有存在实际计算、经营发现或可执行提醒时，才加入老王的判断；否则直接进入固定收尾。

固定收尾：

“我是老王，跨境生意，先算利润，再谈爆单。”

## 交付格式

每次生成：

- 今日简报：三条信号、数字、生效时间、影响卖家、钱怎么变、算账过程、动作、来源。
- A/B 黄金 3 秒。
- HeyGen A/B 纯文本口播稿，时长目标 90–120 秒。
- 核实来源。
- 风险说明。
- 未证实信息单独区块。

口播正文不得出现链接、Markdown、代码块、字幕或镜头提示，复制后即可直接配音。

## 工程边界

- 复用现有 `buildSellerProblemBrief`、发送器、GitHub Actions 与 Codex 自动化，不新建平行内容系统。
- V2 数据文件使用 `format_version: v2`，经 `npm run crossborder:v2:build` 校验后才能发送。
- 私聊发送使用钉钉企业内部机器人 `oToMessages/batchSend`，随后必须调用 `oToMessages/readStatus` 确认接收人及发送状态；只有 batchSend 的 API 返回不算送达。
- 不读取、展示或记录 AppSecret、accessToken、robotCode 或 userId。

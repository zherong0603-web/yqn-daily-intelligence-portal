# 跨境早知道 V2 每日自动化执行规则

这是现有 Codex 定时任务的唯一执行入口。内容规则以 `docs/automation/跨境早知道V2执行规则.md` 为最高优先级。

## 目标

每天北京时间 16:00，在同一个任务内完成“去重检查 → 24/72 小时研究 → 3 条结构化简报 → V2 校验 → 受保护调度 → 钉钉私聊送达核验”。

## 每次执行

1. 用系统 `date` 取得 Asia/Shanghai 真实日期，读取 V2 内容规则、`config/crossborder-v2-intelligence.yaml`、现有样例和自动化 memory。
2. 先查本机 `logs/automation/.crossborder-v2-dws-state.json` 与运行日志。已有 `[crossborder-v2:dws-delivered]` 或状态 `DELIVERED` 时不再重复生成、不再重复发送；状态为 `ATTEMPTED` 且无验证送达时只记录阻塞。旧 GitHub Actions 标记仅用于历史迁移，不再触发新发送。
3. 检查 `data/codex-shadow/YYYY-MM-DD.crossborder-v2.json`。存在则先运行 `npm run crossborder:v2:build -- --file <file>`；日期错、校验失败或内容过期才重新研究。
4. 先搜 24 小时，不足三条再扩至 72 小时。第一条为美国；其后按墨西哥、欧洲优先级取合格信号。不得用旧闻补位。
5. 每条必须有至少一个 `market_signal`，至少一个 `fact_basis`。政策优先官方或平台第一方；媒体数据必须能追溯到原文或指数提供方。每个来源要记录 1–6 个页面可见 `markers`，用于自动核验关键数字、金额和政策文字。`published_at` 必须是来源页面可见日期，不得用检索日期代替。博主爆料只进 `unverified_claims`。
6. 校验器要求三条、美国优先、金额计算、90–120 秒口播、A/B 1–3 秒、纯文本、固定结构、日期和来源全部通过。
7. 运行 `npm run crossborder:v2:build -- --file data/codex-shadow/YYYY-MM-DD.crossborder-v2.json`，再运行 `npm run crossborder:v2:source-check -- --file <file>`。必须退出码 0、`content_valid=true`、`automated_blockers=[]`；正式发送前 source check 必须 `all_ok=true`。
8. 调度前再次确认当天无成功标记、无未确认 attempt；先默认干跑；正式发送只能运行 `npm run crossborder:v2:dispatch -- --date YYYY-MM-DD --live`。该入口只接受 `--date` 与 `--live`，使用本机已授权的钉钉 Workspace CLI，以个人身份发送固定单聊。`dws auth status` 必须显示已登录；未登录时只阻塞发送分支，不读取或记录 token。
9. 单聊发送必须使用每日固定幂等键 `crossborder-v2-YYYY-MM-DD` 和 `--wait-delivery`。命令必须返回 `DELIVERED`、`READ` 或 `UNREAD`，再从目标单聊消息记录中读取到当日简报标题，才能输出 `[crossborder-v2:dws-delivered]` 并记为成功。
10. 发送前把状态写为 `ATTEMPTED`；已有 `ATTEMPTED` 且无验证送达时禁止自动重试。已有 `DELIVERED` 则跳过。状态只记录日期、状态、幂等键和时间，不记录任何账号标识或凭据。
11. 将日期、搜索窗口、三条市场、校验秒数、幂等键、送达状态和送达时间追加到 `logs/automation/yqn-2.md`。
12. 成功后把消息内容留在当前窗口供负责人审阅；CLI 返回成功但看不到对应的目标单聊消息时，不得写成“已送达”。

## 强制边界

- 只推送负责人本人单聊，不发送到任何群聊替代。
- 不读取、展示或记录任何 AppSecret、accessToken、robotCode、userId 或 `dws` 登录 token。
- 不发送旧稿、不改日期伪装新稿、不跳过 90–120 秒和来源校验。
- 美国优先是排序要求，不是编造美国新闻的理由；没有合格美国信号时记录原因。

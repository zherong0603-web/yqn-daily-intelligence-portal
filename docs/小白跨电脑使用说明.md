# 小白跨电脑使用说明

## 先记住一个比喻

GitHub 是“云端档案柜”，里面放代码、当天稿和过去记录；两台电脑是两张办公桌。不要用 U 盘在两张桌子之间搬文件，都去同一个云端档案柜取最新版即可。

## 日常只需要三个入口

1. 看网页历史：https://zherong0603-web.github.io/yqn-daily-intelligence-portal/archive/
2. 看正式发送和失败原因：https://github.com/zherong0603-web/yqn-daily-intelligence-portal/blob/main/docs/运行记录.md
3. 看代码和全部文件：https://github.com/zherong0603-web/yqn-daily-intelligence-portal

只是查看时，打开网址即可。不需要安装，不需要打开终端，不需要点部署。

## 在另一台 Mac 上继续工作

1. 安装并登录同一个 ChatGPT Desktop 账号。
2. 打开 Codex，把下面这句话原样发给它：

   > 请把 https://github.com/zherong0603-web/yqn-daily-intelligence-portal 安装成这台电脑的 YQN 晨报项目，自动完成下载、依赖安装、测试和打开；不要让我使用终端。

3. 等 Codex 说“测试通过”。你不需要复制任何密钥；钉钉发送密钥保存在 GitHub Secrets，不在代码里。

## 让另一台电脑接管自动晨报

默认只让一台长期开机的电脑当“值班员”，推荐 Mac mini。项目安装完后，在 Mac mini 对 Codex 发：

> 请把这台 Mac mini 设为 YQN 晨报的唯一主执行电脑，按 automation/yqn-2.template.toml 安装工作日自动化，设置 ChatGPT 登录后自动启动，验证一次真实运行；成功后再停用旧电脑的同名自动化。

这一步像“交班”：新值班员先实际送成功一次，旧值班员才下班，避免两边都以为对方在工作。

## 不需要做的事

- 不要手工复制项目文件夹。
- 不要把 webhook、token 或 API key 粘贴到聊天。
- 不要在两台电脑同时手工修改同一个文件。
- 不要自己点重试发送；每日防重复逻辑由代码和 GitHub Actions 处理。

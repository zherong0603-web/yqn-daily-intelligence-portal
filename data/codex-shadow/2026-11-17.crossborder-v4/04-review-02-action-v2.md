# 二审二校：卖家动作与经营账

- 审校版本：`03b-editor-cut-v2.md`
- SHA-256：`4aa75682b3f78a705a7af79bd3fce23861090c49a30423888443538bbaec196d`
- 审校角色：独立卖家动作审校
- 审校时间：2026-11-17 14:44 +08:00
- 结论：通过卖家动作审校，可交三审。来源可访问性单独核验。

| 检查项 | 核对结果 |
| --- | --- |
| 谁能采取动作 | 有美国自发货订单、发件账户支持加购、商家或合作仓可决定标签选项。底稿限定合资格货件及可控制出单方式，未暗示平台代发可开启。 |
| 分母与净损 | 筛同类高价货的已投递未收到工单，分母是对应同类货总发货票数，不能用工单数。案例用补发商品成本、补发运费减已获赔款核净损；不合并货未投递、破损、发错等不同问题。 |
| 回本算例 | 100 票 × $10.70 = $1,070；7 × $150 = $1,050，8 × $150 = $1,200。只有与上线相比实际少发生的可预防损失可抵成本；8 是此算例门槛，不是效果承诺。底稿规定保留普通对照组，不能从上月和试用月的原始差值单独归因。 |
| 当日仓库动作 | 先核账户资格、买家收码路径和重派处理/费用。拿到答案前按原方式出单，核准后可用一小批排查出单、收码、重派。对账已勾选票数、实际扣费与验证码导致的重派，具备可执行性。 |
| 什么情况下先不改 | 同类同票数的可预防历史净损上限仍低于服务费，或收码流程未确认。基线用于筛试点，不足以独立证明上线收益。 |

成稿表建议写成“同仓同货类及线路的普通组总发货票数、已投递未收到工单数、该类净损、实际加购票数、扣费、因无码未交付/重派及额外成本”。试一小批先验流程和账单；样本少时不能据此宣布丢件减少。普通组和试用组尽量同仓同货类同线路、同一时期比较；以票数归一化。若当前客单、受众、路线与上月变化，应重新选基线。以上为底稿口径补强，现口播未有与其冲突的事实或结果承诺。
